# Dayline — Voice-First One-Second Journal

**Local-first, ready to test.** Everything runs on-device. No account, no
server, no subscription, no App Store.

Voice → polished journal entry → auto-suggested photos/videos for that day →
left-text/right-photo scrapbook → year grid + trends by tag.

## The local stack (all free, all built-in except where noted)

| Job | Tech |
|---|---|
| Transcription | Speech framework, on-device (`SpeechTranscriberService`). WhisperKit is the planned swappable alternative |
| Polish / tags / mood | Apple Foundation Models (iOS 26, on-device) with guided prompt format; deterministic keyword fallback when unavailable |
| Photo labels / quality | Vision: classification, aesthetics score, face detection (`VisionService`) |
| Photo ranking | `PhotoRanker`: semantic match × aesthetics × faces × favorite — pure, unit-tested logic |
| Open-vocabulary matching ("dinners over the year") | Planned: MobileCLIP (Apple, open-source CoreML) embeddings — see FEASIBILITY notes in repo history |
| Storage | SwiftData on-device; entries store PHAsset localIdentifiers, photos stay in your library |
| Links | LinkPresentation (`LPLinkView`) from URLs detected in your transcript |

## Quick start (Mac)

```bash
./scripts/check-env.sh     # verifies macOS, Xcode 26, iOS 26 SDK, simulators
./scripts/setup.sh         # installs XcodeGen if needed, generates Dayline.xcodeproj
make test                  # simulator build + unit tests
open Dayline.xcodeproj     # then Cmd+R on your iPhone (see TESTING.md)
```

Full walkthrough — signing with a free Personal Team, simulator smoke test,
device test, 7-day expiry, troubleshooting — is in **TESTING.md**.

## Targets & signing
- iOS 26.0, bundle ID `com.steenjennings.dayline`
- Free provisioning (Personal Team) is enough. No Developer Program needed.
- `Dayline.xcodeproj` is generated by XcodeGen and git-ignored — always
  regenerate with `make gen` after pulling changes to `project.yml`.

## Repo layout
- `App/` — entry point + tabs
- `Models/` — `DayEntry` (SwiftData)
- `Services/` — PhotoService, VisionService, PhotoRanker, AssetMediaLoader, SpeechTranscriberService, `AI/Summarizer`
- `Views/` — Today, Scrapbook, Timeline (Year), Trends
- `Tests/` — Summarizer, PhotoRanker, LinkExtractor, PolishResponseParser, PhotoService
- `.github/workflows/` — unsigned simulator build+test on every push (no Apple account needed)
